# Project 2: *Spread*

Demo/template for our [second projects](https://typography-interaction-2627.github.io/project/2/).

> **Students will now work together—with a new reading from those selected by the class in [*Manuscript*](https://typography-interaction-2627.github.io/project/1/)—to express a text deliberately and consistently across devices.**
>
> The goal of this project is twofold: both an effective *collaboration* between partners and also a successful, *responsive* design. Each duo will sketch cooperatively and then implement a joint execution together, via pair programming. The final web page will be responsive for mobile, desktop, and print layouts.

The concept behind this project is to explore how a structured grid can create a bold and expressive visual composition while interpreting the idea of feeling from Michael Rock’s article Hooked on a Feeling. Using a three-column grid, we built the website's structure around the title, making it the central focal point of the composition. The closely spaced lines surrounding the title extend from this focal point to establish the grid, guiding the alignment and positioning of elements throughout the page. Rather than treating the grid as a separate framework, we wanted it to grow out of the title itself, connecting the typography to the overall structure of the website. Inspired by the author's frequent references to moodboards, we used boxes to bring together colors, typography, and graphic elements, exploring how they can communicate different feelings. This concept extends to the website's interaction: hovering over the word Feeling triggers a transition into dark mode, creating a different atmosphere while keeping the content exactly the same. This demonstrates how color alone can transform the user's perception and experience. We wanted to explore how a structured layout can remain flexible and responsive across mobile and desktop while maintaining its visual identity and feeling.
